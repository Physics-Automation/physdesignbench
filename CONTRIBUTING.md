# Contributing

Thanks for your interest in contributing to PhysDesignBench.

**Read the [full contribution guide](docs/contributing/README.md)** for task requirements, proposal and review steps, and reproducibility expectations.

You can [propose a new task](https://github.com/Physics-Automation/physdesignbench/issues/new/choose), review existing tasks, submit additional agent evaluations, or report an issue.

Please discuss a new task with maintainers before implementing it.
