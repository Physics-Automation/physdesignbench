# Contributing to PhysDesignBench

Start with the [contribution guide](docs/contributing/README.md), then review the
[task format](docs/task-format.md), [task requirements](docs/task-guidelines.md),
and [review guidelines](docs/review-guidelines.md).

Propose a task using the repository's task-proposal issue form before implementing
it. Image publication is a separate, explicitly requested maintainer operation;
see [releasing task images](docs/releasing.md).
